# 기술 문서

## 디스크 구성
| 파일 | 내용 |
| --- | --- |
| `SLPS_017.49` | 실행 파일. 메뉴·이름 입력 표·글꼴 테이블·서식 문자열 |
| `GAME.BIN` | 필드 오버레이. 상점·동료·시스템 메시지 |
| `MSG/MSG.DAT` | 마을 사람·동료 대화 블록 |

| `ETC/STRING1.TH4`/`STRING2.TH4` | 12px / 8px 글꼴 |
| `TIM/TITLE.TIM` | 타이틀 그림 |

## 텍스트
Shift-JIS 2바이트 문자열입니다. 한글은 쓰지 않는 SJIS 코드(가나·한자 영역)에 음절을 배정하고, 글꼴 파일의 같은 칸에 갈무리 글리프를 그렸습니다(`cmap.json`). 12px 826자, 8px 197자.

## 창 너비
대부분의 창은 **바이트 수 / 2** 로 칸 수를 계산합니다. 반각 ASCII(공백·`?`)는 화면에서 한 칸을 차지하지만 계산에서는 반 칸이라 창이 좁아지고 글자가 넘칩니다. 그래서 메뉴·확인창 문자열은 공백을 전각 공백(`0x8140`)으로 바꾸고, 예/아니오 확인창 문구는 `?` 를 빼고 7칸 이상이 되도록 했습니다. 말풍선은 16칸에서 강제 줄바꿈되므로 단어 단위로 미리 줄을 나눴습니다.

## 문자열 재배치
`GAME.BIN` 은 번역문이 길어 문자열을 빈 영역으로 옮기고 참조를 고쳤습니다. 포인터뿐 아니라 `lui`/`addiu` 쌍으로 주소를 만드는 코드도 찾아 고치며, 분기 지연 슬롯에 있는 `lui` 도 따로 처리합니다(`fix_branch_hi`). `verify.py`·`hilo_check.py` 로 모든 참조를 검사합니다.

## 조사
`{C1}` `{L2}` `%s` 처럼 실행 중에 이름이 들어가는 자리 뒤의 조사는 받침을 알 수 없어 「은(는)」「이(가)」「을(를)」「와(과)」로 적었습니다.

## 금칙 처리
실행 파일의 줄 끝 금칙 문자 검사(`0x8001ebf8`)를 전각 구두점 대신 반각 `.` `,` `?` 를 보도록 바꿨습니다.
